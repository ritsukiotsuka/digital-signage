# せいくらべの森 — Digital Signage PoC

43インチの赤外線タッチフレーム付きLGモニターを縦置きし、子どもの身長を2通りで測るAndroid PoCです。

- **カメラ計測**: CameraX + ML Kit Accurate Pose Detection + Selfie Segmentation
- **タッチ計測**: モニターに背中を合わせ、頭頂の位置へ横線を引く
- **設置設定**: モニター実寸、床からの高さ、カメラ位置・画角・傾き、補正値を端末内へ保存
- **サイネージUI**: 全画面表示、縦向き固定、大型タッチターゲット、カウントダウンと紙吹雪演出

カメラ映像や写真、計測結果は保存・送信しません。

## 動作環境

- Android 10（API 29）以上
- 縦置きディスプレイ（PoCの初期値は43インチ16:9の表示高 約95.2 cm）
- 赤外線タッチフレーム（Androidから通常のポインティングデバイスとして認識されるもの）
- カメラ方式を使う場合は、全身を撮影できる内蔵またはUSBカメラ

外付けカメラ、前面カメラ、背面カメラの順で自動選択します。

## ビルドとインストール

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Android Studioから `app` 構成を実行しても起動できます。初回のカメラ計測時だけカメラ権限の確認が表示されます。

## 現地キャリブレーション

ホーム右上の歯車から設定します。画面のベゼルではなく、実際に表示される領域を測ってください。

### タッチフレーム

1. モニターを完全に縦向きで固定する。
2. 床から表示領域の下端までを測り、「画面下端の床からの高さ」へ入力する。
3. 表示領域の上端から下端までを測り、「表示領域の実寸（縦）」へ入力する。
4. 身長が既知の人または棒で3回以上試し、一定のずれだけがある場合は「計測結果への加算補正」で調整する。

タッチ計測は次の式です。

```text
身長 = 画面下端高 + 表示領域高 × (1 - タッチY / 画面高) + 加算補正
```

### カメラ

1. カメラ中心の床からの高さを測る。
2. カメラ直下から立ち位置マークまでの水平距離を測る。
3. カメラ仕様の垂直画角を入力する。仕様が対角画角だけの場合は同じ値を入れない。
4. スマートフォンの水準器などでカメラ角度を測る。水平を0度、下向きをマイナスで入力する。
5. 床へ立ち位置マークを貼り、頭から足先まで楕円内に入るようカメラを固定する。
6. 身長が既知の複数人で測り、設置固有の一定誤差を加算補正する。

姿勢推定から足元を、人物マスクから頭頂を求めます。カメラ高と足元の角度から実際の距離を推定し、その距離と頭頂角度から身長を算出します。連続18フレーム中12フレーム以上が揃い、推定値の幅が3.2 cm未満になった場合だけカウントダウンを開始します。

## PoCとしての注意点

- 医療、健康診断、証明用途の測定器ではありません。髪型、帽子、姿勢、床の傾き、レンズ歪み、カメラの自動クロップで誤差が出ます。
- カメラ計測では帽子を外し、かかとを床につけ、腕を下ろし、立ち位置マークに立ってください。
- タッチ計測の方が設置条件を単純化しやすいため、PoCの基準値比較にも利用できます。
- ML Kit Pose DetectionとSelfie Segmentationは、Googleが提供する現行APIですがベータ版です。依存バージョンは固定し、更新時に実機で再評価してください。
- 本番化では既知寸法の校正ボードを用いたカメラ内部・外部パラメータ校正、レンズ歪み補正、端末起動時のキオスク固定、計測ログの匿名化を推奨します。
